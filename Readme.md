# Unnamed embedding-based factory game [WIP]

This is a side project I am working on. It is a factory game that uses word embeddings like (GloVe or Word2Vec) as items to be processed in the game. 

The idea is to create a game where players can build factories that process words and phrases, using the relationships between words as defined by their embeddings. Players can combine words to create new concepts, and the goal is to optimize the word vectors and their production

Currently this project is incomplete.
To build it you need to install Godot 4.7.2 and open the project in Godot, then Project > Export > Export Project
